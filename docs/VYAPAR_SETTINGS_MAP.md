# Vyapar settings and DT Solar Pro

The settings screens in the Vyapar screenshots (phone: Transaction, Invoice Print, Item, menu, business profile; Windows: Add Party, Add Item) were taken one by one. "Done" = a working switch or value in Settings, Simple / Customize (Editable mode). "Already there" = DT Solar Pro had it. "Not added" = left out on purpose, with the reason.

## Transaction
| Vyapar setting | DT Solar Pro |
|---|---|
| Invoice/Bill Number | Not added: numbers are automatic and always printed (accounting rule) |
| Cash Sale by default | Done |
| Billing name of Parties | Done (new field on the party, printed instead of the name) |
| PO Details (of customer) | Done (PO number on sales, supplier invoice number on purchases) |
| Add Time On Transactions | Done (document screen and print) |
| Allow Inclusive/Exclusive tax on Rate | Not added: needs tax-inclusive rates stored on each line and a changed tax calculation; too risky for the accounts |
| Display Purchase Price | Done (average cost and below-cost warning) |
| Show Last 5 Sale Price of Items | Done (click a price to use it) |
| Free Item quantity, Count | Not added: need free-quantity stock and cost accounting |
| Barcode scanning for items | Done (scan box on the document) |
| Transaction wise Discount | Done (and Item wise discount) |
| Round Off Transaction amount, Nearest, To 1 | Done: manual, or automatic nearest / up / down to 1, 5, 10, 50, 100 |
| Share Transaction as | Not added: WhatsApp sends the PDF |
| Passcode for edit/delete | Not added: DT Solar Pro has user accounts and per-user edit and delete permissions |
| Discount during Payment | Not added |
| Link Payments to Invoices | Already there: payments are allocated to invoices, extra money stays as advance |
| Due Dates and Payment terms | Done (switch) and payment terms days on the party |
| Enable Invoice Preview | Done (preview opens after saving a new invoice or quotation) |
| Terms & Conditions, Set Terms & Conditions | Done (switch; the default text is in Settings, Documents, linked from the screen) |
| Additional Fields | Not added: custom fields need a new data model |
